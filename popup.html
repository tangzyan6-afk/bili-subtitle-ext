🥫 字幕罐头 SubCan

  1. 认证：推荐留空——插件直接用你浏览器里的 B站 登录态；也可粘贴 Cookie（见下）。
  2. 输入 UP主 的名称 / 主页链接 / UID，点「获取视频列表」。
  3. 插件在后台列出全部视频并检测字幕，可随时关掉本窗口，稍后再回来看进度（图标上会显示进度）。
  4. 勾选你想下载字幕的视频。
  5. 点「下载并打包」，完成后生成 zip 存到本地。

不会因为切标签/关弹窗而中断：任务跑在后台，关闭本窗口后继续运行，重新点图标即可续看。
Cookie 怎么填：DevTools → Network → 刷新 → 点第一个 www.bilibili.com → Headers → Request Headers → cookie，复制整串（形如 SESSDATA=...; bili_jct=...），粘进下面输入框，点「检测登录状态」验证。
主页链接形如 https://space.bilibili.com/123456，最稳。
