# 🥫 字幕罐头 SubCan

把 B站 UP主 的视频字幕装进罐头带走。

输入 UP主 名称 / 主页链接 / UID，插件自动列出其全部视频、逐个检测字幕、按语言筛选，**勾选后一键打包成 zip 下载到本地**。任务跑在后台，关掉弹窗、切标签都不会中断。

![icon](icons/icon128.png)

## 功能

- **自动识别 UP主**：填昵称、主页链接（`https://space.bilibili.com/123456`）或 UID 都行。
- **全量视频扫描**：分页拉取该 UP主 所有投稿（含 WBI 签名）。
- **字幕检测**：逐个视频（含多 P）检测是否含字幕，列表里标注「有字幕 / 无字幕」。
- **语言筛选**：只下你要的语种——中文（含 AI 字幕）/ 英文 / 其他语种，默认只勾中文。
- **后台运行**：所有任务在 service worker 里跑，关闭弹窗照跑，图标徽标实时显示进度（如 `12/50`）。
- **一键打包**：字幕 JSON 转 SRT，自写 ZIP 打包，文件名形如 `UP主名_2026-09-19.zip`，中文不乱码。
- **Cookie 可选**：同一个浏览器已登录 B站 → 留空即可；换账号/换浏览器可手动粘贴 Cookie，并用 `nav` 接口真实校验。

## 安装

1. 下载或克隆本仓库到本地。
2. 打开 `edge://extensions`（Chrome 是 `chrome://extensions`）。
3. 打开右上角**「开发人员模式」**。
4. 点**「加载解压缩的扩展」**，选择本仓库文件夹。
5. 点工具栏上的罐头图标即可使用。

> 本插件未上架应用商店，属于「开发者模式加载」的自用工具。

## 使用

1. **认证**：推荐留空——插件直接用你浏览器里的 B站 登录态。若需换账号，从 DevTools 复制 Cookie 粘贴进去（Network → 任一 `bilibili.com` 请求 → Request Headers → `cookie` 整串），点「检测登录状态」确认。
2. **输入 UP主**：填名称 / 主页链接 / UID，点「获取视频列表」。
3. **选语言**：勾选要下载的语种（改动后需重新点「获取视频列表」生效）。
4. **勾选视频**：列表里勾选，或点「全选有字幕」。
5. **下载**：点「下载并打包选中字幕」，选保存位置即可。

> ⚠️ B站 字幕（含 AI 字幕 `ai-zh`）**必须登录才会返回**。如果检测到 0 个字幕，先确认「检测登录状态」是否显示已登录。

## 目录结构

```
manifest.json      扩展清单（MV3）
background.js      后台 service worker：抓列表 / 检测 / 下载 / 打包
popup.html/css/js  弹窗界面（只负责显示进度和发指令）
lib/
  auth.js          Cookie 解析、注入、登录校验
  bili.js          B站 接口层（解析 UID / 视频列表 / 字幕 / 语言过滤）
  wbi.js           WBI 签名
  md5.js           纯 JS MD5（浏览器 WebCrypto 不支持 MD5）
  http.js          统一请求层（credentials 处理）
  srt.js           字幕 JSON → SRT
  zip.js           自写 ZIP 打包（STORE，带 UTF-8 标志位）
icons/             图标（16/32/48/128）+ 1024 源图
```

## 常见问题

**Q：切到别的标签页，插件就关了、任务也没了？**
A：已修复。任务全部搬到后台 service worker，弹窗只是显示器。关掉再打开会自动接回进度。

**Q：明明有字幕却识别不到？**
A：多半是**未登录**。B站 字幕现在强制要求登录（SESSDATA），未登录时接口返回空列表。点「检测登录状态」确认是否显示你的昵称。

**Q：下载的文件名是乱码？**
A：已修复。自写 ZIP 现在会写入 UTF-8 标志位（general purpose bit 11），Windows 资源管理器能正确解码中文名。

**Q：下载很慢 / 文件很多？**
A：默认会把视频里所有语种都下下来。在「字幕语言」里只勾你需要的（如只勾中文），文件量和耗时会明显下降。

**Q：返回 `-352` 或风控报错？**
A：B站 风控，隔一会儿再试，或降低并发。
